# 资产清单与预算

> 目标：把「你好签证官」需要的所有美术 / 音频 / UI 资产列成可勾选的清单，标注规格、数量、优先级与单价，
> 让美术生产（AI 出图 + 少量修图）能按批次推进，而不是想到哪画到哪。

## 0. 版本分级

| 级别 | 内容 | 目的 | 资产量 |
|---|---|---|---|
| **P0 原型** | 1 个签证官 + 1 个面试室 + 5 份材料 + 1 个弹窗解谜 + 完整对话循环 | 证明「解谜→材料→话术→怀疑度」这条链路好玩 | 立绘 5 张、背景 1 张、UI 1 套、音效 4 个 |
| **P1 垂直切片** | 面试全 3 幕 + 3 个弹窗解谜 + 2 种结局 + 3 张背景 | 能拿给别人试玩、能剪宣传片 | 立绘 6 张、背景 3 张、UI 全量、BGM 3 首、音效 10 个 |
| **P2 完整版** | 6–8 个关卡 + 配角 + 章节选择 + 存档 | 上架 / 发行 | 立绘 12+ 张、背景 6 张、BGM 5 首 |

**先做 P0。** 下面的清单按 P0 / P1 / P2 标注，没标的默认 P0。

## 1. 角色资产

### 1.1 签证官（核心，唯一必须做好的资产）

男性，40 岁上下，深色西装 + 无领带衬衫，锐利眼神，微下垂的眼皮，表情克制但变化明显。

| 表情 key | 中文 | 触发条件（与 `prototype/engine.py` 的 `mood` 完全一致） | 用途 |
|---|---|---|---|
| `calm` | 平静审视 | 怀疑度 0–19 | 开场、常规提问 |
| `doubt` | 轻微怀疑 | 怀疑度 20–44 | 材料有瑕疵、话术前后不一致 |
| `impatient` | 明显不耐烦 | 怀疑度 45–84 | 追问、催回合 |
| `interested` | 突然感兴趣 | 事件：选项带 `intrigue`（如"硅谷投资人朋友"） | 高光正反馈：你说了句让他意外的话 |
| `caught` | 冷笑 / 识破 | 事件：材料被追问击穿、陈述与材料矛盾；或怀疑度 ≥ 85 | 负反馈顶点、结局前 |

> 优先级：**事件 > 节点指定 > 怀疑度分档**。分档是玩家读取自己处境的主要渠道，所以 4 张数值差分必须一眼可辨；
> `interested` / `caught` 是奖励与惩罚，做成最夸张的两张。

**技术规格**

- 格式：PNG-24 透明背景；**不要**用 JPG（立绘边缘会脏）
- 画布：2160 × 2160（等比缩放到 1920×1080 基准后，人物高度约 900–1100 px）
- 构图：正面偏 3/4 侧（约 15°），视线略低于镜头 —— 玩家是第一人称坐着，签证官俯视/平视你
- 安全区：底部 320 px 会被对话框覆盖，脸和手不要放进去
- 命名：`officer_calm.png` / `officer_doubt.png` / `officer_impatient.png` / `officer_interested.png` / `officer_caught.png`
- 生成方式：**先生成 `calm`，再用它做 reference 派生其余 4 张**（图生图 / 局部重绘），否则脸会飘

## 2. 背景

统一规格：**1920 × 1080**（保留 2560×1440 母版），画面下半部留出对话框的暗区。

| key | 场景 | 用途 | 级别 |
|---|---|---|---|
| `room_interview` | 面试室 · 正面桌子视角 | 主战场，占 80% 时长 | P0 |
| `room_interview_night` | 面试室 · 台灯侧光 / 百叶窗阴影 | 终局压迫、行政审查结局 | P1 |
| `room_docs` | 文件整理室 / 酒店桌面 | 开场独立解谜场景（伪造材料） | P1 |
| `hall_embassy` | 大使馆走廊 / 等候区 | 关卡开场、关卡切换 | P1 |
| `room_window_city` | 窗外城市（昼夜两版） | 叠加层，用于走廊与面试室窗外 | P2 |

**分层建议**（省钱技巧）：背景本体 + 桌面前景（可复用） + 光效叠加层（渐变 / 百叶窗）。
同一房间换光效就能当"另一个场景"用，成本几乎为零。

## 6. 生产流程与成本

### 6.1 AI 出图工作流（Gemini）

1. 写一份**角色设定卡**（外貌 20 个关键词 + 负面词 + 服装 + 光线 + 镜头），固定下来，每次生成都带上。
2. 生成 `calm` 立绘，刷到满意为止（良品率约 1/10，预计 15–30 张里挑 1）。
3. 把满意的 `calm` 作为 reference，逐张派生其余 4 个表情；**只改眉眼和嘴角**，其余保持。
4. 抠图 → 修边（AI 出的透明边缘通常有白边）→ 统一色调 → 检查 5 张脸是不是同一个人。
5. 背景同理：先生成 1 张定死透视与光线，其余场景沿用同一套光线描述词。

### 6.2 修图清单（每张立绘）

抠图去白边、统一肤色、修手指（AI 通病）、补被裁掉的部分、5 张脸对齐、导出正确命名。

### 6.3 成本估算

| 项目 | 自修（不计时薪） | 外包修图 | 备注 |
|---|---|---|---|
| 签证官 5 表情 | 6–10 小时 | ¥60–150/张 → ¥300–750 | 最不能省的一笔 |
| 背景 3 张 | 4–6 小时 | ¥100–250/张 → ¥300–750 | 可用 AI 直出 + 少量修图 |
| UI 全套 | 8–15 小时 | ¥400–1200，或买现成 UI 包 ¥50–200 | 先用免费素材凑，P1 再换 |
| 音频 | 2–4 小时 | 免费素材库 ≈ ¥0 | freesound / Pixabay |
| 字体 | 0 | 0 | OFL |
| 工具订阅 | — | Gemini Plus 已有；大陆 API 写代码 ¥50–200/月 | |

**结论**：P0 原型 **¥0–200**（全部 AI 出图 + 免费音效 + 自修）；
P1 垂直切片 **¥300–1000**（只外包签证官立绘和背景修图，UI 买现成）；
P2 完整版 **¥1600–4000**（立绘 12+ 张、背景 6 张、原创 BGM）。

## 7. 目录结构与命名规范

```
hello-visa-officer/
├─ assets/
│  ├─ characters/officer/officer_{calm,doubt,impatient,interested,caught}.png
│  ├─ backgrounds/{room_interview,room_docs,hall_embassy}.png
│  ├─ ui/{box_dialogue,btn_option_{idle,hover,active,disabled},meter_suspicion,...}
│  ├─ items/{item_passport,item_bank_statement,...}.png
│  ├─ audio/bgm/*.ogg  audio/sfx/*.ogg
│  └─ fonts/*.ttf
├─ prototype/           ← 已实现：数据驱动核心循环
│  ├─ engine.py  puzzles.py  run_demo.py  test_engine.py
│  └─ content/{materials,dialogue,scenario,puzzles}.json
└─ docs/
```

命名铁律：**文件名 = 内容 id**（`bank_statement` 的材料图就叫 `item_bank_statement.png`），代码里永不出现"图 3 副本"。

## 8. 资产验收标准（每张图过一遍）

- [ ] 5 张表情并排放在一起，第一眼看出是同一个人，且情绪差异无需文字说明
- [ ] 缩放到 1280×720 后仍然清楚（很多玩家窗口化）
- [ ] 立绘底部没有重要内容被对话框吃掉
- [ ] 背景在人物站位处对比度足够，脸不会糊进背景
- [ ] 全部资源加起来 < 300 MB（Ren'Py 打包后的目标体积）
